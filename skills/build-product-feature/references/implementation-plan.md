# Feature Implementation Plan

Define how the confirmed feature will fit into the existing system.

Read the confirmed PRD and inspect the relevant implementation. Write the plan with only the details needed to implement the feature:

- The implementation approach.
- The affected parts of the system and how their responsibilities or interactions change.
- The key implementation steps.
- Consequential technical decisions, risks, or assumptions.

Follow established project patterns where they remain suitable. Omit exhaustive inventories, speculative alternatives, unrelated refactoring, and hypothetical future design.
